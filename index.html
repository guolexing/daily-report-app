数据备份 / 恢复

📖 使用说明

1. 日报录入：每天选择项目、填写工作内容保存即可，一天可多条。

2. 周报生成：自动按「周一~周日」汇总本周，按项目生成总工时与任务总结（参考模板格式），可复制/下载 MD、Excel。

3. 月度考核报表：自动汇总本月出勤（有日报即出勤；周末与法定节假日计入休息，调休上班日计入应出勤）。内置 2024–2026 年国务院办公厅节假日安排，日历上用角标标出节日名与调休上班日。

4. 数据存储：数据保存在本机 MySQL（「数据管理 → MySQL 数据存储」配置主机/端口/用户名/密码/库名，保存并测试连接后自动读写）。数据可移植：点「⬇ 导出全库备份」生成 .json 备份文件，拷贝到任意电脑安装本 APP 后点「⬆ 从备份恢复」即可完整还原（恢复前自动备份当前数据）。

5. 若需把已有 Excel 日报导入：在 Excel 中另存为 CSV（逗号分隔、UTF-8），列顺序为：日期,项目名称,工作时长,今日工作,明日计划,备注。粘贴到下方导入。

6. AI 汇总（可选）：在「数据管理 → AI设置」填写 OpenAI 兼容接口的 Base URL / Key / 模型（如 DeepSeek），保存后点「测试连接」；然后在周报页点「🤖 AI 汇总周报」、月报页点「🤖 AI 润色复盘」即可。不配置 Key 时，规则版照常可用。

7. 周报栏目列表（推荐用法）：周报页「周报模板」选择「栏目列表」，下方会出现栏目列表编辑区：

  • 栏目名：想汇报什么就加什么，如 本周进展 / 本周未完成 / 下周工作计划 / 风险与问题。可「➕ 添加栏目」「🗑 删除」。
  • 撰写要求（提示词）：每个栏目可单独填写该栏目的写作要求，例如"按项目分组，每项写清做了什么、关键结果与工时"。留空则按默认规则生成。填好后点「💾 保存栏目设置」。
  • 示例解析：不想写要求？点「📄 粘贴示例」把该栏目期望的样子（公司模板片段或上次的汇报）粘进去，再点「🤖 AI 解析为要求」，AI 会自动生成该栏目的撰写要求。

点「🤖 AI 按栏目生成周报」，AI 会按各栏目要求 + 日报数据 + 任务管理数据生成：本周进展按项目汇总本周日报（含工时）；本周未完成逐条列出任务管理中未完成的任务；下周工作计划根据下周计划任务、逾期需顺延任务及日报后续计划生成。

7. 从 CC Switch 一键导入：若本机装有 CC Switch（供应商配置在 ~/.cc-switch/cc-switch.db），在「AI设置」点「⚡ 从 CC Switch 一键导入」即可读取全部供应商（名称/BaseURL/Key/模型），选一个自动填入，再点「保存AI设置」。会自动记忆上次选择的供应商，下次导入时自动选中。注意：Codex 型供应商可能不兼容 /chat/completions，导入后请用「测试连接」验证。

8. 一键载入历史日报：数据管理 →「📥 一键载入历史日报（2025-05~2026-09）」可把入职至今的 333 条日报（历史日报.xlsx 转换而来，已含 8月/9月初）合并进应用，自动去重；或点「⬆ 导入数据(JSON)」手动选择「日报工具/历史日报备份.json」。之后周报/月报即可基于完整历史生成。

9. 项目管理：「② 项目管理」可添加/改名/删除项目，并可将项目完结（完成后点「✔ 完结」，默认不再出现在日报/任务的项目下拉中；勾选「显示已完结项目」可恢复查看）。项目完结不影响历史日报/任务数据。

10. 任务管理：「③ 任务管理」可把项目细分为任务（任务名称、计划开始时间、计划完成时间、实际完成时间）。日报录入时只需选「所属任务」，项目自动带入（任务=项目细分）；无合适任务时（如学习/会议）再直接选项目。任务的实际完成工时 = 挂载日报工时自动累加。状态自动判定：已填实际完成时间=已完成；超过计划时间未完成=已逾期；其余=进行中。任务随 JSON 备份一起导出/导入。

11. Windows 任务开始提醒：任务填写「计划开始时间」（如 09:00），桌面版内置服务每 30 秒自动检查，到点（可设提前 5 分钟）弹出 Windows 原生通知提醒开始处理。在「数据管理 → Windows 通知」可开关/调提前量/发测试通知。

CSV 快速导入（从Excel复制/导出）

支持逗号或制表符(Tab)分隔；日期格式 YYYY-MM-DD；小时数为数字；今日工作必须填写。

🤖 AI 智能导入（任意格式日程 → 日报）

把任意格式的日程 / 日历 / 聊天记录 / Excel 复制内容粘贴到下方（不限定格式），AI 会自动识别日期、项目、工时与工作内容，生成日报预览后再一键导入。需要已配置 AI（数据管理 → AI设置）。
